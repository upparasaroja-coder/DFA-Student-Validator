
# Student Login & Validation Using DFA

## 📌 Project Overview

This project is a web-based Student Login and Validation system developed using the concept of Deterministic Finite Automata (DFA).

The system validates:
- Student email address
- Student password

It also displays the DFA validation path for better understanding of the automata process.

## 🎯 Objectives

- To understand the practical application of DFA.
- To validate student email addresses using DFA logic.
- To validate password requirements.
- To build a simple and user-friendly web interface.
- To demonstrate Automata Theory concepts through a working website.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Deterministic Finite Automata (DFA)

## ✨ Features

- Student login validation
- Ashoka College email validation
- Password strength validation
- DFA state/path display
- Valid and invalid input handling
- Responsive web interface

## 📧 Email Validation

Valid email format:

`studentID@ashokacollege.in`

Example:

`242ta05375@ashokacollege.in`

## 🔐 Password Requirements

The password should contain:

- At least 8 characters
- Uppercase letter
- Lowercase letter
- Digit
- Special character

Example:

`Hello@123`
